# Checklist final de entrega

## Maqueta

- [ ] La aplicación abre en Android Studio y en un teléfono real.
- [ ] Se probó en orientación vertical.
- [ ] Se probó en orientación horizontal.
- [ ] LVK permite cambiar el sentido horario/antihorario.
- [ ] LCK permite cambiar corrientes entrantes/salientes.
- [ ] Se puede seleccionar un nodo del cubo.
- [ ] Se puede cambiar el nodo GND.
- [ ] Se probaron circuitos de una, dos y tres mallas.
- [ ] Se probó el constructor libre de mallas.
- [ ] Se observan corrientes, voltajes y potencia por elemento.
- [ ] Las animaciones de flujo se observan correctamente.
